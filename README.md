# End-to-End Data Science Project: German Tech Careers and Salary Optimization

An end-to-end data processing, analysis, and production-ready decision automation project simulating IT recruitment and salary benchmarking operations in Germany.

## Project Overview
This project executes the complete data science lifecycle on an IT professional dataset within the German market (München, Berlin, Frankfurt). The objective is to clean unstructured survey responses, engineer financial metrics, visualize salary distributions across roles, and deploy an automated rule-based decision engine to evaluate candidate compensation packages.

## Tech Stack and Skills Demonstrated
* Python: Core engineering, logic optimization, and function building
* Pandas: Data loading, advanced categorical/numerical imputation using medians, and column mutations
* Matplotlib: Data aggregation and categorical bar chart visualization
* Software Logic: Development of production-ready decision criteria functions

## Analytical and Data Pipeline
1. Data Loading: Modeled a large tech career survey database containing multi-city demographic variables.
2. Data Cleaning and Imputation: Handled missing entries by replacing null roles with unknown categories and numerical salaries using stable median distributions.
3. Feature Engineering: Automated the calculation of a 40% German tax deduction, net Euro earnings, and live conversion rates into Indonesian Rupiah (IDR).
4. Visual Analysis: Aggregated salary records to pinpoint the most lucrative tech professions via targeted bar plotting.
5. Decision Automation: Deployed a production-grade logical function evaluating candidates based on urban economic zones, technical expertise demand, and seniority filters.

## Automated Decision Engine Results
The system successfully validates senior high-demand tech profiles. Testing a Data Scientist candidate profile based in München with 6 years of industry experience correctly returns:
* Status: APPROVED for EUR 6,000+ Premium Salary Package
* Actionable Metric: Proceed with immediate recruitment and premium EU visa sponsorship workflow.
